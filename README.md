# 自像比对 (Self Check) · MaiBot 插件

当聊天里有人发图问「这是不是你 / 像不像你」时，很多机器人靠人设里写死的「认图规则」回答，
结果要么机械认领、要么被对方一否定就改口。这个插件把判断交给视觉模型：拿待判图与**你自己
提供的角色基准图**比一次，把结论作为一条客观材料追加到本轮 planner 请求尾部，由机器人照着说。

> 仓库地址：https://github.com/weiyu104/maibot-self-check

## 它做什么 / 不做什么

- 触发条件：**本轮有图 + 文本含自我指向短语**（默认「像你/是你/画你/…」），没被问到就不产生任何模型调用。
- 群聊默认还要求 @ 了机器人或叫了它的名字，避免把群友之间的对话误判成在问它。
- 图文常分两条消息发送，插件会往前看若干条找图和问句，并限制问句时效。
- 结果分 `same / similar / different / unclear` 四档，按档位附带一句行为要求，避免「刚认完又推翻自己」。
- **只改这一轮请求**：不写数据库、不改图片描述、不发消息、不动人格。超时/无密钥/无基准图/输出非法时静默跳过，绝不影响正常回话。
- 同一张图（按字节 hash）结论缓存 30 分钟，并有每日调用上限和逐轮去重。

## 安装

1. 通过插件中心安装，或把本仓库内容放到 `plugins/lanyan_self_check/`（目录名按宿主规则）。
2. 重载插件 / 重启 MaiBot。
3. 🔴 如果本机已经装过同功能的旧版或自改版，**不要重复启用**，否则同一轮会注入两条注记。

## 配置（🔴 必做，否则插件不会工作）

插件中心禁止仓库根目录包含 `config.toml`，所以仓库里只有 `config.example.toml`。

```bash
cp config.example.toml config.toml
```

然后改这三处：

1. **放基准图**：把你角色的正/侧/背三视图存成 `refs/three_view.jpg`（或改 `[refs] primary` 指向别的路径）。
   本仓库**不附带任何形象图**，详见 `refs/README.md`。没有基准图时插件安静地什么都不做。
2. **填外貌判据**：把 `[prompt] compare` 里所有【方括号占位内容】换成你自己角色的三条主特征
   （发色发型 / 瞳色 / 脸型）和「什么算本质不同」。身份一致性主要靠基准图承载，文字只作补充。
3. **确认模型**：`[engine] model` 换成你可用的、支持一次请求两张图的视觉模型。
   `provider_name` 指向宿主 `model_config.toml` 里的配置项；`base_url` / `api_key` 建议留空，
   让插件自动读取宿主配置，**不要把密钥写进插件配置文件**。

其余可调项：触发关键词、回看条数、群聊 @ 闸门、超时、缩放边长、每日上限、缓存时长、
注入模板与四档结论文案。改 `config.toml` 热重载即生效，改 `.py` 需要重载插件。

## 依赖与开销

- 需要 `maibot_sdk >= 2.12.0`、宿主 `>= 1.3.10`，能力：`config.get` / `message.get_by_id` / `message.get_recent`。
- `Pillow` 用于缩放（缺失时插件仍能跑，只是不缩放、token 更高）。
- 每次比对 = 一次带两张图的视觉模型请求，费用按你所用服务商的单价计。
  插件会在数据目录写 `cost.jsonl` 记录 token 与估算值；**估算单价只是示例，实际以服务商账单为准**。
- `[debug] trace = true` 可打开逐轮诊断日志，排查完请关掉。
