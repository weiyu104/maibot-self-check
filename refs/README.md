# refs/ ：请放你自己的角色基准图

插件用 `[refs] primary` 指向的图片作为「图 1」，与聊天里收到的图做比对。
**公开仓库不附带任何形象图**，请自行准备：

- 推荐：同一角色的正 / 侧 / 背三视图拼成一张，保存为 `refs/three_view.jpg`。
- 至少一张正面、特征清晰、无遮挡的图也能用；可用 `[refs] fallback` 指定备用图。
- 路径按插件目录解析，也可以填绝对路径。
- 图片会被缩放到 `[engine] max_ref_side`（默认 1280）后再送检。

图片文件已被 `.gitignore` 排除（`refs/*.jpg` 等），不会误传进公开仓库。
如果这张图属于你不想公开的角色设定/私人素材，请不要把它放进任何公开仓库或 Issue 附件。

放好图之后，别忘了同步修改 `config.toml` 里 `[prompt] compare` 的【方括号占位内容】，
写成你角色的三条主特征——否则模型没有判据，结论会乱。
